# Restaurant Menu Landing Page

A modern restaurant menu landing page developed using HTML5 and CSS3. The project showcases a premium dark-themed restaurant interface with beautifully designed food and beverage sections.

## ✨ Features

- Premium dark UI
- Responsive layout
- Food & drinks showcase
- Elegant card-based design
- Modern typography
- Hover effects
- Clean and structured code

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Purpose

This project was built as part of a frontend web development assignment to practice CSS positioning, responsive layouts, and modern UI design principles.
